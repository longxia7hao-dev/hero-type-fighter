## 白話
靈域戰把怪打到門檻後，開「施印」窗念短題；成功進圖鑑（只收藏）。圖鑑卡框＝ART-CATCH 金邊深紫玻璃；魔物立繪等製作人板，空窗不塞假怪。

## A｜戰鬥中：可施印態

門檻：`common` HP≤40；`rare` HP≤20（MAX=100）。達標後**暫停出招**，勿自動搶麥。

```
┌─ fight（現有血條／舞台／語音區）─────────────┐
│  …                                              │
│  ┌─ #catch-ready ─────────────────────────────┐ │
│  │  可施印 · 普通／稀有                        │ │
│  │  [ 施印 ]   ← #btn-seal 金邊主鈕＋seal 小圖 │ │
│  │  [ 逃 ]     ← #btn-flee-catch 次鈕           │ │
│  └────────────────────────────────────────────┘ │
│  語音出招列：達標時 disabled／遮罩，等按施印    │
└─────────────────────────────────────────────────┘
```

| 掛點 | 規格 |
|------|------|
| `#catch-ready` | 金邊玻璃條；稀有標可略亮金邊 |
| `#btn-seal` | 主 CTA；內嵌／旁掛 `#catch-seal`（`art/catch/seal.png`） |
| `#btn-flee-catch` | 逃＝不收入、不給勝金 |
| 擊倒後 | 另選「施印嘗試」／「收下金幣離開」（門檻已滿才可施印） |

## B｜施印窗 `#seal-modal`（捕捉窗）

按「施印」後疊在戰鬥上；單題短語音。

```
┌─ #seal-modal（金邊深紫玻璃）──────────────┐
│  施印                                      │
│         ┌─────┐                            │
│         │印符 │  #catch-seal 飛／靜皆可     │
│         └─────┘                            │
│  ┌─ 提示卡（同 prompt-panel 語）─────────┐ │
│  │  ① ㄧㄣ     或  SEAL                    │ │
│  │  ② 印       （英＝整詞一關）             │ │
│  │  時限環 4.5–6s · mic 狀態沿用           │ │
│  └───────────────────────────────────────┘ │
│  綠段／聽到行：VOICE-002／003 同規可套      │
│  [ 取消＝視同失敗選項入口 ]                  │
└────────────────────────────────────────────┘
```

| 態 | UI |
|----|-----|
| 進行 | 倒數＋mic；題面短於戰鬥題 |
| 成功 | 印命中短 scale＋金光 →「已收入圖鑑」／「重複」→ 結算 |
| 失敗／超時 | 「施印失敗」→ **再打**／**逃**（`#btn-seal-retry`／`#btn-flee-catch`）；魔物 HP 維持施印前 |

注音可①②；英文首包只整詞一關。`kind:'seal'` 與戰鬥題分池。

| 掛點 | 規格 |
|------|------|
| `.codex-card`／`.codex-frame` | 金邊 2–3px、圓角 14–18、底板 `castle-glass`；方角立繪窗 |
| `.codex-art` | `object-fit: contain`；無板＝夜紫＋月／塔 watermark＋「等待造型板」 |
