# BRIEF-CATCH-001 — 靈域捕捉（疊在現有冒險上）

提出：主策劃（總監點名）  
給：主程式／介面HUD／美術／品管  
狀態：**定稿可掛。** 不拆 BRIEF-RPG-001；語音雙段核＋VOICE-003 容錯沿用。公司酒局掛起。

## 白話
在冒險裡可進「靈域」遇怪。先用語音把怪打到可捕捉門檻，再念一道短「施印」題；過了就進圖鑑（只收藏，不上陣）。普通／稀有兩檔。施印失敗可再打或逃。

---

## 一、流程（不拆現殼）
既有：選角 → 商店（可跳過）→ 戰鬥 → 勝金回商店。

新增入口（擇一掛，預設）：
- 標題／結算加「靈域」鈕；或商店旁「進靈域」。
- 靈域戰結束回商店或標題（同 session 金幣／庫存／圖鑑保留）。

```
進靈域 → 抽一隻靈獸遇敵
  → 語音雙段對打（現核）
  → 魔物 HP ≤ 捕捉門檻 → 開「施印」短題
  → 施印成功 → 圖鑑＋1（只收藏）→ 結算
  → 施印失敗 → 選：再打（續戰）／逃（回商店或標題，不收入）
  → 勇者 HP＝0 → 敗北（同現包；不收入）
  → 逃：隨時可按（施印前／失敗後）；不收入、不給勝金
```

打到 0 血＝擊倒（可給現包勝金），**不自動捕捉**；要捕捉必須走施印。擊倒後可選「施印嘗試」（門檻已滿足）或「收下金幣離開」。

---

## 二、捕捉門檻
| 稀有度 | id | 魔物 HP 門檻（MAX=100） | 說明 |
|--------|-----|------------------------:|------|
| 普通 | `common` | **≤ 40** | 較易進施印 |
| 稀有 | `rare` | **≤ 20** | 要多打幾招 |

門檻達成時戰鬥暫停語音出招，HUD 亮「可施印」；玩家按「施印」才出短題（勿自動搶麥）。

戰鬥數值沿用：`MAX_HP=100`、`MONSTER_DMG=14`、招傷＝題庫×職業倍率、技能／物品可用。

---

## 三、施印短題（語音，單段或超短雙段）
- 模式跟玩家當前注音／英文設定。
- **比戰鬥題短**：時限 **4500–6000 ms**；容錯跟 CHANGE-VOICE-003。
- 注音例：單符＋例字（ㄇ→媽）或一字（「印」「封」「靈」）。
- 英文例：短詞 `SEAL`／`BIND`／`CATCH`（可先字母再整詞，或只整詞一關——首包採 **只整詞一關** 降摩擦）。
- 成功＝圖鑑寫入該靈獸 id（已有則標「重複」仍顯示成功，不堆疊實體）。
- 失敗／超時＝不收入；選再打（魔物 HP 維持施印前）或逃。

首包施印題庫（≥8，可擴）：

| mode | display | expect | timeMs |
|------|---------|--------|-------:|
| zhuyin | ㄧㄣ → 印 | 音對過①／「印」過②；或單段「印」 | 5500 |
| zhuyin | ㄈㄥ → 封 | 同上 | 5500 |
| zhuyin | ㄌㄧㄥ → 靈 | 同上 | 5500 |
| zhuyin | ㄓㄨ → 住 | 同上 | 5500 |
| english | SEAL | SEAL | 5000 |
| english | BIND | BIND | 5000 |
| english | CATCH | CATCH | 5000 |
| english | MARK | MARK | 5000 |

實作可複用 `VoicePrompt`；建議 `kind: 'seal'` 與戰鬥題分開抽。

## 四、稀有度與遇敵
| 稀有度 | 權重（首包） | 勝金（擊倒） | 圖鑑標籤 |
|--------|-------------:|-------------:|----------|
| common | **70%** | 同現包 `35+floor(勝/2)` | 普通 |
| rare | **30%** | 現包勝金 **×1.5**（四捨五入） | 稀有 |

首包靈獸 id（立繪可暫用現 `monster.png` 色變／之後換檔）：
- common：`spirit_ember` 焰靈、`spirit_dew` 露靈、`spirit_pebble` 石靈
- rare：`spirit_moon` 月靈、`spirit_void` 虛靈

---

## 五、圖鑑（只收藏）
- 資料：`id / name / rarity / caughtAt`（session 或 `localStorage`）。
- UI：列表＋大圖＋稀有標；**不可選為出戰、無數值養成**。
- 入口：標題「圖鑑」；空狀態白話「還沒印到靈獸」。

---

## 六、明確不做
- 不拆選角／商店／語音雙段核。
- 捕捉寵不上陣、不改四職技能表。
- 不新增多人／即時對戰。

## 驗收鉤
1. 靈域可遇敵；HP 到門檻才可施印。  
2. 施印成→圖鑑有；敗→再打／逃。  
3. 普通／稀有門檻與權重可感。  
4. 現有冒險流程仍通；語音核未改語意。
