# CHANGE-VOICE-001 — 收音雙段出招（取代打字）

提出：主策劃（製作人定案）  
給：主程式／介面HUD／品管  
狀態：**定稿待掛。** 未改碼。試玩針點仍可先維持打字直到本單上線。  
公司酒局掛起；魔刃 STOP。

## 白話
不要打字了。麥克風聽你念。  
**注音：** 螢幕顯示 `ㄓㄠ` → 先念對「ㄓㄠˋ」→ 再念「罩！」兩段都過才砍。  
**英文：** 顯示 `A-P-P-L-E` → 先念字母 → 再念 `APPLE`，兩段都過才砍。  
念錯或超時＝被魔物打。

---

## 一、出招流程（每一招）
1. 出題：顯示本招 `display`（注音串或字母串）＋第 1 段聽筒狀態。  
2. **第 1 段**：玩家念 `stage1`；過關才開第 2 段。  
3. **第 2 段**：玩家念 `stage2`（漢字詞／英文整詞，建議結尾可帶「！」語氣）。  
4. 兩段都過 → 勇者攻擊，扣魔物 `damage`。  
5. **任一段失敗**（辨識為錯／放棄）或 **總時限到** → 魔物攻擊，勇者扣 `MONSTER_DMG`（現包 **14**）。  
6. 下一招；血到 0 勝負（現包 `MAX_HP=100`）。

打字輸入、螢幕注音鍵「當出招」＝**主循環作廢**（鍵可留作教學提示，不送招）。

---

## 二、題庫格式
```
id, mode: 'zhuyin'|'english',
display,          // 畫面上大字
stage1Expect,     // 第1段要比對的語音目標（規範字串）
stage2Expect,     // 第2段要比對的語音目標
stage1Hints[],    // 容錯別名（小寫／去空白後比）
stage2Hints[],
timeMs,           // 整招總時限（兩段共用一條倒數）
damage
```

### 注音版規則
| 欄 | 例（製作人） | 說明 |
|---|---|---|
| display | `ㄓㄠ` | 可不帶調號；畫面上清楚 |
| stage1Expect | `ㄓㄠˋ` | **必須含聲調**（ˊˇˋ˙ 或一／二／三／四聲口語） |
| stage2Expect | `罩` | 對應國字；可接受 `罩！` |
| 順序 | 先 stage1 再 stage2 | 念反＝該段失敗 |

### 英文版規則
| 欄 | 例（製作人） | 說明 |
|---|---|---|
| display | `A-P-P-L-E` | 字母用 `-` 或空白隔開皆可顯示 |
| stage1Expect | `A P P L E` | 逐字母；允許「A」「Ay」等見容錯表 |
| stage2Expect | `APPLE` | 整詞；不分大小寫 |
| 順序 | 先字母再整詞 | 直接念 APPLE 跳過字母＝第1段失敗 |

## 三、容錯（Web Speech）
引擎：瀏覽器 **Web Speech API**（`zh-TW`／`en-US`）。只取當前段的 `interim`＋最終結果。

### 共同
| 規則 | 值 |
|---|---|
| 比對前處理 | 去空白、全形轉半形、英文小寫；注音保留調號符號 |
| 置信度 | 最終結果 `confidence≥0.55` 才採納；否則當「沒聽清」可重試至時限內 |
| 同段重試 | 時限內可一直聽；**錯判明確**（聽到明顯別詞）＝立刻失敗挨打 |
| 明確錯 | 結果正規化後與 expect／hints **無交集** 且長度≥1 |

### 注音第1段容錯 hints 例
- 調號：`ㄓㄠˋ` ≡ 口語含「四聲／去聲」且聲母韻母對  
- 允許 ASR 回傳漢字再反查：若引擎吐 `照／罩／趙`，只要對應拼音為 `zhao4`／注音 `ㄓㄠˋ` 可視為 stage1 過（**stage2 仍要「罩」本字**）  
- 禁止：別調（`ㄓㄠˊ`）當過

### 英文第1段容錯
- 字母名：`A`≡`ay`／`eh`；`P`≡`pee`；連念 `A P P L E` 或 `A, P, P, L, E`  
- 順序必須對；多／少字母＝錯

### 英文第2段容錯
- `APPLE`≡`apple`；允許輕微複誦一次；禁止複數／別詞（`apples` 可列入 hint 可選，預設**不收**）

## 四、時間與傷害（對齊現包量感）
| 項 | 值 |
|---|---:|
| `MAX_HP` | 100（不改） |
| `MONSTER_DMG`（錯／超時） | **14**（不改） |
| 單音／短詞 timeMs | **5000**（雙段比打字緊，給聽） |
| 中長詞 timeMs | **6500～8000** |
| damage | 沿用難度檔：短 **12～16**、中 **18～22**、長 **24** |

第1段建議佔總時限前 **55%** 軟提示（HUD 可顯示段標）；時限仍是整招一條，到 0＝整招失敗。

## 六、權限與裝置
- 進戰鬥前請求麥克風；拒＝卡在模式選單並白話提示。  
- 無 Web Speech／不支援 `zh-TW`：注音模式顯示「此瀏覽器暫不支援注音收音」，引導用 Chrome／Edge 或改英文版。

---

## 七、HUD 需求（給介面）
- 聽筒狀態：關／聽第1段／聽第2段／辨識中／成功／失敗  
- 大字：`display`＋當前段標「① 注音／字母」「② 字詞」  
- 倒數條＝整招 `timeMs`  
- 錯／超時回饋同現包被打

---

## 驗收
1. 注音兩段都對才出招；只對一段不出招。  
2. 英文字母＋整詞兩段都對才出招。  
3. 錯或超時勇者掉血 14。  
4. 場上不再靠打字送招。
