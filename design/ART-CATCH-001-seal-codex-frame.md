## 1. 施印符（Seal）

### 用途
捕捉／封印互動時的印記 UI（按鈕、飛出印、命中閃一下）；小、遠看可認。

### 造型鎖
| 項 | 規格 |
|----|------|
| 外形 | 圓印或方印皆可，**外圈金邊**＋內夜紫底 |
| 中心 | 簡易符文／月牙＋塔剪影線稿（單色金或淺金），**不畫具體魔物臉** |
| 材質 | 賽璐璐貼紙感：金邊 `#ffd76a`、底 `#1c0e3a`～`#2a1558`、可微光 |
| 尺寸 | UI 用建議 96²／128² PNG 透明底；動效用同 stem 可再出 `@2x` |
| 禁止 | 塗鴉噴漆、寫實蠟封照片、無金邊灰模 |

### 建議檔名
`public/art/catch/seal.png`（主）  
可選：`seal-glow.png`（命中高光層，可程式疊）

### 給主程式
掛點建議：`#catch-seal` 或飛印 sprite；命中時短 scale＋金邊亮度，**不改戰鬥語音邏輯**。

## 2. 圖鑑卡框（Codex frame）

### 用途
CATCH 圖鑑列表／詳情：框住「製作人板」魔物立繪；框與底板先定，立繪到位後只換 `<img>`。

### 造型鎖
| 項 | 規格 |
|----|------|
| 外框 | **金邊** 2–3px（`--gold-edge`），圓角 14–18px |
| 底板 | 深紫玻璃 `rgba(28,14,58,.72)`；可內側 1px 金暈 |
| 立繪窗 | 上方／中央方窗，`aspect-ratio: 1` 或 3:4；`object-fit: contain`；**方角、不圓裁** |
| 標題條 | 卡底或窗下：職／名用金字；副標淺紫字 |
| 空窗佔位 | 無板時：窗內夜紫＋淡月／塔線稿 watermark＋文案「等待造型板」；**禁止自填假魔物** |
| 稀有度（可選） | 僅金邊亮度／角飾層級差，不另開螢光霓虹風 |

### 建議檔／CSS
- 框可純 CSS（對齊 HUD-MOONCASTLE 金邊玻璃），不必先出框 PNG。
- 若需九宮格框圖：`public/art/catch/codex-frame.png`（透明中空）。
- 立繪到位後路徑建議：`public/art/catch/monsters/<id>.png`（本票不產檔）。

### 給主程式／HUD
列表卡＋詳情卡共用同一框語；詳情可加大立繪窗。語音／對打流程不因圖鑑改動。
